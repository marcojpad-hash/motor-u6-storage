I. MOTOR V5 — NÚCLEO BAYESIANO
============================================================

1. Incertidumbre contextual de un marcador [CANÓNICA]

Para un marcador m con confianza c_m:

    sigma_m(t) = 1 - c_m

Implementación exacta:
    Marker.uncertainty() = 1.0 - confidence

Fuente: Engine_V5_CANONICO_SOLO.py.

2. Actualización Bayesiana de una hipótesis [CANÓNICA]

Para probabilidad previa p y likelihood l:

    p' = [p l] / [p l + (1-p)(1-l)]

Antes:
    l <- max(0.001, min(0.999, l))

Si el denominador es cero:
    p' = p

3. Evidencia favorable [CANÓNICA]

Si un token tiene peso favorable w:

    l = w
    p <- Bayes(p, l)

4. Evidencia contraria [CANÓNICA]

Si un token tiene peso contrario w:

    l = 1 - w
    p <- Bayes(p, l)

5. Corrección por estado de evidencia de la ficha [CANÓNICA]

Multiplicadores:

    primary_verified       = 1.0
    secondary_verified     = 0.7
    outdated               = 0.5
    unverified             = 0.4
    contestado_academicamente = 0.4
    contradicted_partial   = 0.2
    contradicted            = 0.1

Transformación del peso original w:

    w_efectivo = 0.5 + (w - 0.5) * multiplicador

Si no existe estado conocido:
    multiplicador = 1.0

6. Epsilon / masa residual de incertidumbre [CANÓNICA]

Una vez por observación:

    p <- (1-epsilon)p + epsilon*0.5

El epsilon conceptual no debe confundirse con la tolerancia numérica de coma flotante.

7. Indeterminación [CANÓNICA]

Con umbral de indeterminación 0.1 y tolerancia numérica 1e-9:

    indeterminado <=> |p - 0.5| < 0.1 - 1e-9

8. Dirección [CANÓNICA]

    direction = 0, si indeterminado
    direction = +1, si p > 0.5
    direction = -1, si p < 0.5

9. Delta de hipótesis del corte [CANÓNICA]

Para marcadores m_1 ... m_n:

    delta_H(t) = (1/n) * sum_i sigma_i(t)

donde:
    sigma_i(t) = 1 - confidence_i

Si no hay marcadores:

    delta_H(t) = 0

10. Delta mínimo dinámico [CANÓNICA]

    delta_min(t) =
        delta_min_base
        + (delta_min_max - delta_min_base) * delta_H(t)

11. Sorpresa/dispersión [CANÓNICA]

Si hay menos de dos marcadores:

    sigma_sorpresa(t) = 0

Si hay n >= 2:

    sigma_sorpresa(t) =
        sqrt[(1/n) * sum_i (sigma_i(t) - mean_sigma)^2]

Es desviación estándar poblacional (pstdev), no muestral.

12. Azar interno [CANÓNICA]

Sea:

    spread = sigma_sorpresa(t) * sigma_sorpresa_scale

Entonces:

    p_azar(t) =
        clip(0.5 + U[-spread, +spread], 0, 1)

donde U es uniforme aleatoria.

13. Monte Carlo de p_azar [CANÓNICA]

Estimación inicial:

    sigma_estimada_inicial =
        sigma_sorpresa(t) + delta_min_base

    n_inicial =
        max(min_n, floor[(sigma_estimada_inicial/epsilon)^2])

limitado por:

    n_inicial <= max_n

Por defecto documentado:
    min_n = 50
    max_n = 200000
    batch = 200

Error estándar:

    SE = sigma_muestral / sqrt(n)

Se detiene cuando:

    SE < epsilon

o cuando se alcanza max_n.

14. P indeterminado [CANÓNICA]

    p_indet = 0.5

15. Peso de evidencia [CANÓNICA]

    peso_evidencia =
        max(0, 1 - delta_min(t) - sigma_sorpresa(t))

16. P final [CANÓNICA]

    p_final =
        peso_evidencia * p
        + delta_min(t) * p_indet
        + sigma_sorpresa(t) * p_azar(t)

con:

    p_indet = 0.5

p_final es estado del motor, NO probabilidad calibrada del futuro.

17. Convergencia interna del tablero [CANÓNICA]

Para hipótesis no indeterminadas:

    strength_h =
        (favor_h - contra_h) / (favor_h + contra_h)

Se toma signo y magnitud:

    signo_h = +1 si strength_h >= 0
              -1 si strength_h < 0

Se selecciona la mayoría por cantidad de signos.

Entonces:

    convergencia =
        (N_mayoría / N_decididas)
        *
        mean(|strength_h| en la mayoría)

No es una métrica de predicción futura.

II. CAMPO 244 / TRAZA
============================================================

18. Delta temporal de cada hipótesis [PLUGIN]

    Delta_i(t) = P_i(t) - P_i(t-1)

Para cada corte se conserva el vector completo de deltas.

19. Cambio de rango [PLUGIN]

Si rank_de y rank_a son posiciones ordinales:

    delta_rank = rank_de - rank_a

Un valor positivo significa que la hipótesis subió posiciones.

20. Interrelación entre hipótesis [PLUGIN]

Para dos series de deltas:

    r_ij =
      sum_t[(Delta_i(t)-mean_i)(Delta_j(t)-mean_j)]
      /
      sqrt(
        sum_t(Delta_i(t)-mean_i)^2 *
        sum_t(Delta_j(t)-mean_j)^2
      )

Es correlación de las trayectorias de delta.

Con menos de dos observaciones no se calcula.
Con varianza prácticamente cero el código devuelve 0.

El resultado se interpreta como POSIBILIDAD DE INTERRELACIÓN, no identidad causal.

21. Neto de una hipótesis [PLUGIN]

    neto_i = P_i(último) - P_i(primero)

III. REPORTE 3D
============================================================

22. Top-1 [PLUGIN]

    H_t = argmax_i P_i(t)

Es el letrero, no el hallazgo completo.

23. Movimiento [PLUGIN]

Para cada hipótesis:

    d_i(t) = P_i(t) - P_i(t-1)

Se ordenan por:

    |d_i(t)|

y se muestran los N_MOV principales.

Configuración documentada:
    N_MOV = 3

24. Persistencia [PLUGIN]

Se buscan hipótesis distintas de H_t entre el Top-12 que cumplan:

    P_i(t) >= piso

Configuración:

    piso = 0.62
    N_PERSIST = 3

Las primeras tres se registran como "no_se_apagaron".

25. Serie de una hipótesis [PLUGIN]

    serie_i = [P_i(t_0), ..., P_i(t_n)]

    P_i(t) = 0.5

26. Delta de la curva [PLUGIN]

    d_i(t) = P_i(t) - P_i(t-1)

27. Codificación de forma [PLUGIN]

Con epsilon de forma eps:

    signo(d) =
        "↗" si d >= eps
        "↘" si d <= -eps
        "→" en otro caso

28. Piso de inclusión [PLUGIN]

Solo se conserva la curva si:

    max(serie_i) >= piso

Configuración:
    piso = 0.62

29. Subida previa al Top-1 [PLUGIN]

Si el Top-1 ocurre en i_top:

    subio_antes =
        exists j < i_top tal que d_i(j) >= eps

La intención es detectar una subida antes de que la hipótesis sea el letrero.

30. Conjunto de tokens por corte [PLUGIN]

31. Solape Jaccard [PLUGIN]

Casos especiales:

VI. AQUILES / RESOLUCIÓN DE FOTO
============================================================

37. Solapamiento Top-K [PLUGIN]

Para conjuntos/listas A y B:

    overlap(A,B) = |A ∩ B| / max(|A|,|B|)

Casos:
    ambos vacíos -> 1
    uno vacío -> 0

38. Cambio de p_H entre remuestreos [PLUGIN]

    delta_H_replica = |p_H(n) - p_H(n_prev)|

39. Condición de foto quieta [PLUGIN]

    H_quieta =
        [ |p_H(n)-p_H(n_prev)| <= 0.02 ]
        AND
        [ I >= 0.02 ]

40. N_min [PLUGIN]

N_min es el menor n para el cual la condición anterior se mantiene durante:

    m = 3

ventanas consecutivas.

41. Resolución creciente [PLUGIN]

    n_k = n_0 * 2^k

con:

    n_0 = 32

por tanto:

    32, 64, 128, 256, 512, ...

42. Fusible [PLUGIN]

    N <= 8192

Si se alcanza el fusible sin N_min:

    NO_ENCONTRADO_FUSIBLE

El fusible NO se interpreta como N_min.

43. Media de p_H en bootstrap [PLUGIN]

Para n réplicas:

    p_H(n) = (1/n) * sum_j p_H,j

44. Intensidad residual I [PLUGIN]

    I(n) = max(0.02, mean(I_j))

si existen valores I_j; de lo contrario:

    I(n) = 0.02

45. Ganador modal [PLUGIN]

Se selecciona el nombre con mayor frecuencia entre las réplicas:

    winner = mode(winner_j)

46. Top-K bootstrap [PLUGIN]

Se cuentan los nombres de los Top-K de cada réplica y se ordenan por frecuencia.

Si el caller da carga:

    carga ∈ {+, -, 0}

Si no:

    carga = + si delta_neto > 0
            - si delta_neto < 0
            0 si delta_neto = 0

49. Nota dramática [PLUGIN]

    se_nota = [d_max >= umbral]

Configuración documentada:

50. Selección proporcional de corte [PLUGIN]

Para fracción f:

    j = round(f*(n-1))

limitado a:

    0 <= j <= n-1

51. Posiciones Field [PLUGIN]

Con n >= 4:

    acto 1       -> 0
    plot point 1 -> max(1, n//4)
    punto medio  -> n//2
    plot point 2 -> min(n-2, 3n//4)
    acto 3       -> n-1

52. Posiciones McKee [PLUGIN]

    f = [0, 0.3, 0.55, 0.8, 1.0]

53. Volteo de carga [PLUGIN]

Entre cortes consecutivos:

    volteo si
      carga_t != carga_{t-1}
      AND ambas cargas != 0

Resultado:

    carga_{t-1} -> carga_t

XVI. FIBONACCI / PHI — EXPERIMENTO EXTERNO DE ARQUITECTURA

76. Ecuación AR2 recuperada:

    x_t = x_{t-1} + x_{t-2}

77. Polinomio característico:

    r^2 = r + 1

o:

    r^2 - r - 1 = 0

78. Raíces:

    r_1 = (1 + sqrt(5))/2 = phi
    r_2 = (1 - sqrt(5))/2 = -1/phi

79. Ratio asintótico:

    F_{n+1}/F_n -> phi

80. Tasa logarítmica:

    s = ln(phi)

81. Representación Z/Laplace del experimento:

    H(z) = z^2 / (z^2 - z - 1)

Polos:

    phi
    -1/phi

82. SINDy recuperó:

    x_t = 1*x_{t-1} + 1*x_{t-2}

El experimento recuperó la misma estructura por tres rutas:
    AR2 -> polinomio característico -> phi
    SINDy -> ecuación de recurrencia -> phi
    Z/Laplace -> polos -> phi

Esto fue una validación externa de recuperación estructural, NO una demostración de metafórmula universal.
