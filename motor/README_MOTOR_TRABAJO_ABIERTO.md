# U6 Motor de trabajo — hipótesis abiertas y geometría multicapas

Versión: `V15.3_UNICO_WORKING_OPEN_HYPOTHESES_20261020_R1`.

Este paquete es un **motor alterno de trabajo**. No modifica el motor canónico ni el catálogo canónico de 244 patrones. La salida primaria es el conjunto de hipótesis de cardinalidad variable y una apuesta multiescenario construida después del conjunto. Los campos H1/H2 se conservan únicamente por compatibilidad con los módulos históricos.

La geometría multicapas integrada ejecuta el sidecar temporal/relacional, el adaptador de convergencia/Tusi y el teseracto descriptivo antes de cerrar el conjunto de hipótesis. La vectorización micro/meso/macro, la inercia, la aceleración y los giros por candidato entran a `rank_fusion`; los enlaces de trazabilidad explícitos pueden conservar hipótesis complementarias fuera del conjunto mínimo 021. Los pesos son estructurales, no probabilidades calibradas.

## Ejecución

```bash
python correr_estandar.py inputs/THEMISTOCLES_FREEZE_480BC_CATALOG_REPAIR_R2.json nombre salida.json
```

Para persistencia de StinkBox fuera del ZIP, configurar `STINKBOX_STORAGE_ROOT` o `STINKBOX_STORAGE` a una carpeta duradera. No sustituir ese almacenamiento al actualizar el motor.
