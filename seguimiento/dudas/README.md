# Dudas técnicas

Registra aquí dudas concretas que se pueden resolver con inspección del repositorio, contratos, trazas o artefactos.

## Antes de abrir una duda

1. Buscar en `FEEDME_ACTUALIZADO.md`, contratos, informes, avances y código.
2. Formular una pregunta verificable, no una impresión general.
3. Registrar archivo/caso, evidencia disponible, comprobaciones realizadas y qué falta.
4. Intentar resolverla con las herramientas disponibles antes de preguntar al creador.

## Formato por entrada

Crear `AAAA-MM-DD_duda_<tema>.md` con:
- Pregunta concreta
- Contexto/caso
- Archivos y evidencia consultados
- Comprobaciones hechas
- Respuesta o estado pendiente
- Enlaces a commit/pruebas si aplica

Al resolverla, enlazar el registro de cierre en `seguimiento/resueltos/`.
