# Resueltos con evidencia

Una incidencia solo se marca resuelta si hay evidencia de la solución.

Cada cierre `AAAA-MM-DD_resuelto_<tema>.md` debe incluir:
- Incidencia original enlazada
- Causa raíz identificada
- Cambio aplicado y commit
- Prueba ejecutada y resultado, o indicación exacta de que no se pudo ejecutar
- Recibo/hashes/artefactos relevantes
- Estado final del CEB si aplica

No confundir “documentado” con “resuelto”, ni “archivo creado” con “prueba ejecutada”.
