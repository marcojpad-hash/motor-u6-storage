# Decisiones del creador

Usar esta carpeta solo para decisiones que requieren criterio o autorización del creador. No enviar aquí tareas que se resuelven leyendo el código o las reglas.

Cada entrada `AAAA-MM-DD_decision_<tema>.md` incluye:
- Decisión requerida en una frase
- Opciones reales y consecuencias
- Evidencia y restricciones relevantes
- Recomendación técnica, separada de los hechos
- Estado: abierta / decidida
- Resolución y fecha cuando exista
